# Experimental methodology

## The question

Does a learned world model provide capabilities that better function
approximation does not? The interesting claim is not "world models have lower
MSE" — it is that they support **counterfactual reasoning, long-horizon
planning, and transfer to worlds they were not trained on**.

So the design separates four things that are easy to confuse:

| confound | control |
|---|---|
| more parameters | parameter counts matched within one order of magnitude and reported |
| more optimisation | identical gradient-step budget for every learned system |
| more information | identical observation window; graph view carries identical information |
| multi-step training objective | an observation-space model gets the *same* open-loop objective with no learned latent, and a latent model is trained with `L = 1` |

If the observation-space control matches the latent models, the advantage was the
objective, not the latent state, and the report must say so.

## Target grouping, and why

A single pooled MSE over the 112 observation features was measured first, and it
was misleading. Two artifacts dominate it:

1. **The difference identity.** `ret1_*` and `pool_move_*` are already one-step
   differences. Predicting their *change* is mostly "next return ≈ its mean". A
   ridge fit scores **+0.99** skill on that group while learning nothing about
   the world. These features carry ~68% of the total normalised delta variance,
   so they dominate any pooled score and compress every model into the same
   number.
2. **The martingale.** `logprice_*` changes are generated by a regime-switching
   geometric random walk. They are unpredictable *by construction*. Best linear
   skill on level features: **+0.017**.

Targets are therefore grouped by mechanism:

| group | features | best linear skill | role |
|---|---|---|---|
| `price` | `ret1_*`, `pool_move_*`, `logprice_*` | +0.99 (identity) | reported, excluded from the composite |
| `price_level` | `logprice_*` only | ≈ 0 | **leakage canary** |
| `protocol` | utilisation, rates, depth, basis, realised vol, gas | +0.06 | endogenous, learnable |
| `agent` | the focal account's own balance sheet | +0.45 | action-dependent |
| `population` | per-cluster aggregates | +0.03 | crowd state |

The headline metric, **decision-state skill**, pools `agent` and `protocol` —
the quantities a planner actually needs.

### The leakage canary

Price-level changes cannot be predicted by any legitimate system. A model
scoring clearly above zero there is reading the exogenous process, which would
mean an information leak. The canary is computed on every split and carried in
the composite's `raw` block.

## References

Skill is `1 - MSE(model) / MSE(reference)`. Three references are reported:

- **persistence** — "nothing changes";
- **linear AR** — a closed-form ridge autoregression on the same window, which
  already contains whatever a linear model of that window can extract;
- **best naive** — whichever of the two has lower error *on that split*.

The third is the headline. A fitted linear reference can blow up on held-out
worlds (it does, on `ood_unseen_agents`), and scoring against it alone would hand
every model a free skill of 1.0.

## Splits

Splits are **disjoint episode-seed ranges**, never slices inside an episode:

| split | seeds |
|---|---|
| train | `[0, 100_000)` |
| val | `[100_000, 200_000)` |
| test_iid | `[200_000, 300_000)` |
| `ood_<scenario>` | `300_000 + 10_000 * i` |

Because a world's entire future is a deterministic function of its seed, episodes
from different ranges share no state, no noise and no agent draws. Slicing within
an episode — the usual shortcut — would put the same regime, the same balance
sheets and the same price path on both sides of the split.

`bwm/data/audit.py` verifies seed disjointness and reports exact-duplicate
observation rows across splits. Both run as tests and as part of every report.

Adversarial and coordinated archetypes are **excluded from the training
distribution**, so "unseen agent type" is a real held-out axis rather than a
relabelling. A test asserts this for every training seed.

## Counterfactual protocol

For a probe state `S_t`:

1. Fork the world; take the factual action `a_f`; continue with the behaviour
   policy for `L` steps, **recording the tail**.
2. Fork the world again; take the counterfactual action `a_cf`; replay the *same*
   tail.
3. Ground-truth effect = the difference between the two observation trajectories.

Both branches see identical exogenous noise (counter-based seeding), so the
difference is the causal effect of the intervention at `t` and its downstream
propagation through the other agents.

Two intervention types: **substitute** (`a_cf` is a different legal action) and
**removal** (`a_cf = NOOP`, i.e. "what if A had not occurred?").

The model is asked the same question purely in imagination: encode at `t`, roll
both action sequences through the latent, subtract.

**The control that matters.** Most single actions barely move a deep market, so a
model predicting "no effect" gets a respectable MSE. The headline is therefore
skill against the **zero-effect predictor**. Persistence scores exactly 0.0 by
construction, and a test asserts it. Positive skill means genuine causal signal;
zero means none, whatever the one-step MSE looks like.

## Control protocol

Every policy runs on the **same** episodes (same world seeds, same focal account,
same action menu, same observation window) and is charged **exactly one real
environment step per decision** — asserted by a test.

Reported: total return, Sharpe, Sortino, maximum drawdown, episode-wise regret
against the best system on that same episode, action entropy, and an
adaptation delta (second-half minus first-half normalised reward) as the
learning-from-consequences signal.

## Composite index

Six components, each in `[0, 1]`: interpolation, extrapolation, event
calibration, counterfactual, long horizon, planning.

Constructed so it cannot hide anything:

- every component is stored raw alongside the composite;
- unsupported components are `None`, never silently zero;
- `coverage` records how much of the index a system answered, and systems are
  only comparable at equal coverage;
- the report prints the components next to the composite, always.

## Artifact audits

The lab is designed to surface its own problems, and two were found this way.

**Trade-size artifact.** A true-simulator planner earned +395% in one episode,
with single steps worth +98% of net worth. Auditing the net-worth decomposition
showed the governance token has no lending market, so arbitrageurs cannot short it
and cannot correct an over-price; the AMM price drifted ~30x from the oracle while
wealth was marked at the oracle. A protocol-level per-trade price-impact cap
(`EnvConfig.max_swap_frac`) fixed it: median basis is now 1–9% and the largest
single-step gain fell to 5% of net worth.

**LP payout bug.** The liquidity-withdrawal shock burned LP shares without paying
out the underlying tokens, destroying value and penalising every LP in a crisis.

Both are recorded here rather than quietly patched, because the headline results
depend on the world being economically sane.

## What would falsify the hypothesis

Stated in advance:

- if the observation-space control matches the latent world models on
  counterfactual skill and OOD decision-state skill, latent state is not doing
  the work;
- if the Transformer baseline matches the world models on long-horizon skill, the
  advantage is sequence modelling, not world modelling;
- if `wm_plan` does not beat `wm_greedy`, planning is not paying for itself;
- if `unified` does not beat its best component, the unified architecture is not
  justified;
- if the oracle planner (perfect dynamics) does not beat the learned planner by a
  wide margin, the environment does not reward dynamics knowledge and the whole
  comparison is uninformative.
